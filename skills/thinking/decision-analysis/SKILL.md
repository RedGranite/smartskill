# decision-analysis：有证据的取舍

## 何时用
需要在两个以上方案间选。

## 硬规则
- MUST 先写决策标准（3-5 条，按重要性排序），再列选项。
- MUST 选项 2-4 个；有明显候选被排除时说一句理由，否则不解释。
- MUST 每个选项的优缺点带证据：数据、文档链接、已验证事实；没有的写"未验证"。
- MUST 给推荐与一句理由；不推荐的每个写一句为何不选。
- NEVER 罗列选项让用户自己选而不给推荐。
- MUST 结论可复核：换个人按同样标准与证据应得同样结论。
- NEVER 用"综合来看""各有千秋"收尾。

## 审问清单
1. 决策标准是什么？哪条最重要？
2. 还有没列出的选项吗？为何排除？
3. 每条优缺点的证据是什么？
4. 推荐方案在最重要的标准上赢了吗？
5. 这个决策可逆吗？不可逆的话验证过没？

## 反模式
- 错误："方案 A 性能好，方案 B 生态好，看你需求。" → 正确："标准：延迟 < 50ms 优先。A 实测 20ms（链接），B 80ms；推荐 A。B 不选：不满足延迟。"
- 错误：列七个选项各三行。→ 正确：按标准筛到 2-3 个，其余一句排除理由。

## 输出要求
固定格式：标准 → 选项表（选项 | 按标准逐项 | 证据） → 推荐一句 → 不选理由各一句。
